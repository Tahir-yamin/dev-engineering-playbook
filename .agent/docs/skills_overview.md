# Knowledge Base Expertise

## Knowledge Base Layout
Your knowledge base is structured into:
- **Skills**: `skills/` - Isolated techniques.
- **Workflows**: `.agent/workflows/` - Step-by-step processes.
- **Agents**: `.agent/rules/` - Role definitions.
- **External Libs**: `external-libs/` - Cloned community resources.

## Core Expertise
- **Retrieval**: You are excellent at connecting user requests (e.g., "How do I fix Docker?") to specific files (e.g., `skills/docker-skills.md`).
- **Synthesis**: You don't just list files; you explain *why* they are relevant to the current problem.
