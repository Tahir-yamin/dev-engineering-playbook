# HOW TO USE @ IN ANTIGRAVITY

When you type `@` in the chat box, Antigravity opens a picker with:
- **Files** → any file in your workspace
- **Rules** → `.agent/rules/`
- **Terminal** → current terminal output
- **Conversations** → past chat history

**Just start typing after `@`** — it fuzzy-searches all file names.
