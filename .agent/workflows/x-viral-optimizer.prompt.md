# 🚀 Workflow: X Viral Optimizer & Publisher

Use this workflow to transform technical articles, PDFs, or research into high-performance X threads.

---

## 🏎️ Execution Steps

### 1. Source Analysis [ANALYZER]
1. Read the provided source document (PDF, Markdown, or URL).
2. Identity 3 "Controversial" or "High-Value" insights.
3. Identify the target SimCluster (e.g., #AI, #Robotics, #Fintech).

### 2. Virality Evaluation [EVALUATOR]
1. Run a baseline check against the X technical weights.
2. Check for "Link Penalty" risks.
3. Assign a **Virality Score (0-100)**.
4. **STOP** if score < 70. Refine the Hook before proceeding.

### 3. Thread Orchestration [ORCHESTRATOR]
1. Draft a 3-7 part thread based on the source.
2. **Tweet 1 (The Hook)**: Must be a pattern-interrupt (Max 280 chars).
3. **Internal Expansion**: Break the technical bulk into bulleted lists with emojis.
4. **Engagement CTA**: Final tweet must contain an open-ended question.

### 4. Visual Injection
1. Use `generate_image` to create a "Premium/Cinematic" visual for Tweet 1.
2. Aesthetic instruction: "Hyper-realistic, dark mode, vibrant highlights."

### 5. Publication Strategy
1. Determine the "Golden Hour" based on local time and target demographic.
2. Generate the **"Brand Manager's Final Sign-off"** with the posting checklist.
