## Skill #1: AI-Augmented Literature Synthesis
Using specialized 2026 tools to map research gaps and ensure a "Q1-level" novelty argument.

### When to Use
- Determining the conceptual framework for a new paper.
- Writing the "Related Works" or "Introduction" sections.
- Responding to reviewer comments about "missing citations."

### Implementation
1. **Tooling**: Use **Elicit** or **SciSpace** for systematic data extraction from PDFs.
2. **Gap Discovery**: Use **ResearchRabbit** to visualize citation networks and identify "islands" of unlinked research.
3. **Consensus Matching**: Use **Consensus.app** to verify if your hypothesis aligns with or contradicts the existing 2025/2026 literature corpus.

## Skill #2: "Intellectual Hesitation" & Burstiness
Humanizing technical text to mirror the linguistic patterns of senior academics, thereby passing advanced AI detectors.

### When to Use
- Drafting the "Discussion" and "Conclusion" sections.
- Refining any text generated via LLMs (Claude/GPT).

### Implementation
- **Hedging**: Convert absolute statements (e.g., "This proves that...") to nuanced ones (e.g., "Our findings suggest a strong correlation, indicating that...").
- **Sentence Variation**: Mix short, punchy declarative sentences with long, complex compound-complex sentences (Human "Burstiness").
- **Personal Voice**: Use specific examples from your own lab or unique methodologies that an LLM would not have in its training data.

## Skill #3: Citation Integrity & Verification
Cleaning AI-suggested citations to avoid "hallucinations" which are common red flags in Q1 peer review.

### When to Use
- Finalizing the bibliography.
- Checking LLM-generated references.

### Implementation
- **Smart Citations**: Use **Scite.ai** to check if the cited paper is "supporting," "mentioning," or "contrasting" your claim.
- **DOID Checks**: Cross-reference every AI-generated citation with **Semantic Scholar** or **Google Scholar** via a systematic script or manual check.

## Skill #4: Technical & LaTeX AI Workflows (Engineering Focus)
Leveraging AI for complex technical formatting and equation handling without breaking the "No AI Authorship" rule.

### When to Use
- Writing papers for **IEEE**, **Elsevier Energy**, or **Applied Energy**.
- Handling complex mathematical notations and data tables.

### Implementation
- **Overleaf AI (2026)**: Use the "Error Assist" and "TeXGPT" features within Overleaf Labs for fixing compilation errors. *Do not use it to write the core logic.*
- **OpenAI Prism**: Use as a collaborative workspace for real-time AI drafting and citation auto-population. Note: Ensure you export to standard LaTeX before submission for cleanliness.
- **Mathpix**: Screenshot handwritten lab notes or whiteboard derivations to convert them instantly into clean LaTeX code.
- **Data-to-Latex**: Use Python scripts (pandas/matplotlib) generated by agents to output `.tex` tables directly from simulation CSVs, avoiding manual entry errors.

## Skill #5: Engineering Simulation Data Analysis
Using autonomous agents to effectively analyze and present simulation results (CFD/FEA).

### When to Use
- Analyzing large datasets from ANSYS, OpenFOAM, or Simulink.
- Preparing "Results" sections for Energy journals.

### Implementation
- **Agentic Analysis**: Use **DataSage AI** or **Claude Analysis Agents** to scan CSV outputs for anomalies that a human eye might miss.
- **Physical AI Interpretation**: Use "Physical AI" prompts (grounded in physics laws) to verify if the simulation results make physical sense before inclusion.
- **Lesson Learned Agents**: Check internal "Lesson Learned" databases (if available) to ensure the simulation setup aligns with previous successful Q1 submissions.

## Skill #6: Privacy-First AI Research (Prismer)
Using open-source, self-hosted tools to manage sensitive research data without third-party cloud exposure.

### When to Use
- Research involves proprietary industrial data (common in Energy/Engineering).
- You need a unified platform that combines reading papers with writing LaTeX.
- Institutional policy forbids uploading unpublished drafts to ChatGPT/Claude.

### Implementation
1. **Platform**: **Prismer** (GitHub: `Prismer-AI/Prismer`).
2. **Setup**: Clone the repo and run locally or on a private server.
   ```bash
   git clone https://github.com/Prismer-AI/Prismer.git
   ```
3. **Workflow**:
   - **Context Management**: Upload your PDF library directly to Prismer.
   - **Data Analysis**: Use the integrated Jupyter Notebooks to run Python analysis on your data *within* the drafting environment.
   - **Drafting**: Use the built-in AI-assisted LaTeX editor.
   - **Citation Check**: Use Prismer's unique verification feature to prevent citation fabrication locally.

## Skill #7: Systematic Review Automation (PRISMA)
Using AI to automate the rigorous "PRISMA 2020" systematic review process.

### When to Use
- Writing a Review Paper (highly cited in Q1 journals).
- Managing thousands of search results from Scopus/Web of Science.

### Implementation
- **Review Tools**: Use **Prismaid** (GitHub: `open-and-sustainable/prismaid`) to automate the screening and tagging of manuscripts based on your inclusion criteria.
- **Protocol Adherence**: Ensure your AI workflow explicitly maps to the 27-item PRISMA 2020 checklist. Use the AI to *generate* the specific flowchart numbers, but verify the exclusion reasons manually.
